WHAT THIS IS
  A complete rebrand of P-Stream into "NEXUS", plus a working set of
  streaming providers (including your self-hosted MovieBox VPS with
  multi-language dub audio), a notification system, and full docs for
  AI coding agents (Antigravity / Claude CLI / Cursor).

════════════════════════════════════════════════════════════════
  TO RUN  (Windows)
════════════════════════════════════════════════════════════════
  1. Extract this zip.
  2. Double-click  setup-nexus.bat      (or run setup-nexus.ps1)
     → clones P-Stream into C:\Users\reah.m.e.camingawan\Music
     → applies ALL NEXUS patches, providers, audio, docs, .env
     → installs deps and starts the dev server
  3. Open the project's  .env  and fill in:
        VITE_TMDB_READ_API_KEY   = your TMDB v4 read token
        VITE_MOVIEBOX_API_URL    = your MovieBox VPS URL
        (recommended) VITE_CORS_PROXY_URL, VITE_M3U8_PROXY_URL
  4. Restart:  pnpm run dev      →  http://localhost:5173

════════════════════════════════════════════════════════════════
  TO RUN  (Antigravity / Claude CLI / Cursor / any AI IDE)
════════════════════════════════════════════════════════════════
  Point the agent at this folder. It will auto-read:
      AGENTS.md        (agent rules)
      CLAUDE.md        (same, for Claude)
      .cursorrules     (same, for Cursor)
      PROJECT_CONTEXT.md
      docs/            (BACKENDS, PLAYER_INTEGRATION, HOW-TO-RUN, ...)
  These explain the ENTIRE project: how sources work, how the two
  backends (TMDB-Embed HuggingFace + MovieBox VPS) work, how to fix
  providers, and exactly what to wire inside the cloned repo.

════════════════════════════════════════════════════════════════
  IMPORTANT — what you must provide
════════════════════════════════════════════════════════════════
  I do NOT have your private secrets, so .env ships with clearly
  marked  <<< FILL IN >>>  placeholders:
     • TMDB v4 read token   (themoviedb.org/settings/api)
     • MovieBox VPS URL      (where you deployed Moviebox-API)
     • CORS / M3U8 proxy     (recommended, fixes stream CORS)
  The app runs without them but can't stream until TMDB + at least
  one provider backend are set.
